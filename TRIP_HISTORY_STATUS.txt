📊 ROOT CAUSE ANALYSIS
───────────────────────────────────────────────────────────────────────────────

The Issue:
  Completed and cancelled trips were FILTERED OUT before history view could access them

Original Code Flow:
  API returns: [active, active, completed, cancelled]
       ↓
  fetchRequests() filters: removes completed/cancelled
       ↓
  setRequests(activeRequests) ← ONLY active trips stored!
       ↓
  tripHistory tries to use requests state
       ↓
  No completed/cancelled trips to display
       ↓
  Tabs remain BLANK 😞

The Fix:
  API returns: [active, active, completed, cancelled]
       ↓
  Store ALL: setAllRequests(fetchedRequests)
  Store ACTIVE: setRequests(activeRequests)
       ↓
  Dashboard uses requests (active only)
  History uses allRequests (all trips)
       ↓
  Filtering works on complete dataset
       ↓
  All tabs populate correctly ✅
